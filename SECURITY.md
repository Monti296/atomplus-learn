# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately using GitHub's "Report a vulnerability" option under the Security tab of this repository, or email [security contact: to be filled in by the product owner].

Include what you found, how to reproduce it, and the possible impact. We aim to acknowledge reports within 5 working days.

## Supported versions

Only the latest version on the `main` branch is supported.

## Rules for contributors

- Never commit secrets or real user data. See the README.
- Security rules for the project are in the security plan (SR-1 to SR-29), which every change must respect.
